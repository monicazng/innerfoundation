# Inner Foundation

Official website for [Inner Foundation](https://inner.foundation/) — a coaching practice for founders, engineers, and technical leaders.

## Tech Stack

- HTML, CSS, vanilla JavaScript
- No frameworks or dependencies
- Hosted on GitHub Pages

## Structure

```
├── index.html              # Home
├── manifesto.html
├── testimonials.html
├── archivo.html            # Spanish essay index
├── archivo/
│   ├── integridad.html
│   └── voces.html
├── style.css
├── site.js                 # Theme, nav menu, logo animation, Substack embed
├── 404.html                # GitHub Pages not-found page
├── CNAME                   # GitHub Pages custom domain
├── assets/
│   ├── favicon.png
│   ├── about-portrait.png
│   └── summary_large_image.png   # Open Graph / Twitter card
├── LICENSE
└── README.md
```
